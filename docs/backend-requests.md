## 시뮬레이터가 정한 값

MockBackend 가 계약 의미를 흉내 내며 정한 값. 백엔드가 다르게 정하면 시뮬레이터를 바꾼다.

| 값 | 내용 | 근거 |
|---|---|---|
| 센터 코드 | `CDC01` | 백엔드 CDC-1 |
| 구역 글자 | A 냉동 · B 냉장 · C 상온 (MFC 시뮬레이터 기준, R-08) | 사용자 |
| 층 배치 | 백엔드 CDC-2 배치, 글자만 R-08: 5F 상온(C01~C20) / 6F 냉장(B01~B18) / 7F 상온(C21~C32)+냉동(A01~A12), 층마다 ≈2,867평 | chilgok-dc.md |
| 차량·도크 | 차량은 지하 도크, 롤테이너는 승강기로 오르내림(사용자) | 설계 §3.1 |
