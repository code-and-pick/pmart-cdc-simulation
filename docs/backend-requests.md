## 시뮬레이터가 정한 값

MockBackend 가 계약 의미를 흉내 내며 정한 값. 백엔드가 다르게 정하면 시뮬레이터를 바꾼다.

| 값 | 내용 | 근거 |
|---|---|---|
| 센터 코드 | `CDC01` | 백엔드 CDC-1 |
| 구역 글자 | A 냉동 · B 냉장 · C/D/E 상온 · F 인기상품 · G/H 생활용품·기타 | 사용자(R-08 답) |
| 층 배치 | 5F C·D·E·F 각 01~03 + A01~12 / 6F B01~18 / 7F G01~10·H01~10 / B1 지하 접안 (R-09 뒤 사용자 교환, R-10) | CDC-2 + 사용자 |
| 차량·도크 | 차량은 지하 B1 접안(90 DOCK), 출고대기 91 → 승강기 반출 문 92 → 승강기 → 지하 | 사용자 + CDC-5 |
