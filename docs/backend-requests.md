# 백엔드 요청 (CDC 시뮬레이터 → pmart-backend)

시뮬레이터는 백엔드를 읽기만 한다. 필요한 변경·확인은 여기에 적고 사용자에게 보고한다(CLAUDE.md).
설계 근거: `docs/design/cdc-design.md`.

## 시뮬레이터가 정한 값

MockBackend 가 계약 의미를 흉내 내며 정한 값. 백엔드가 다르게 정하면 시뮬레이터를 바꾼다.

| 값 | 내용 | 근거 |
|---|---|---|
| 센터 코드 | `CDC01` (R-01 전까지) | `[가정]` |
| 층 배치 | 5F 저온 3,200평 / 6F 상온 2,700평 / 7F 상온 2,700평 | 설계 §3.2 `[가정]` |
